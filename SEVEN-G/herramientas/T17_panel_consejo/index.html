T17 · Generador del panel del consejoConvierte el registro de iniciativas T01 en el panel de IA para el Consejo y en el registro de recomendaciones (T18)

Qué es T17, en una frase: es un generador, no una aplicación en la que se introducen datos. Las iniciativas se mantienen en el registro T01; T17 lee ese registro y genera —o vuelve a generar, cada vez que el registro cambia— el panel del consejo completo, su versión para el móvil y el registro de recomendaciones. Si solo quiere ver el resultado, abra el panel de ejemplo: panel completo · panel para el móvil. El resto de esta página explica cómo generarlo con sus propios datos.

Este conector toma el JSON completo que exporta el registro de iniciativas T01 de SEVEN-G y lo convierte, sin volver a introducir datos, en el panel de IA para el Consejo (completo y móvil, sincronizados) y, si el registro trae recomendaciones, en el registro de recomendaciones. Los paneles los genera el motor incluido en la carpeta motor/ (versión 8, con embudo y ciclo de vida; origen: AI en el Consejo, MIT, mismo autor): no hace falta ningún otro repositorio.

El registro es la única entrada de datos: cada iniciativa se da de alta en T01 como una oportunidad en un CRM y el panel se reconstruye desde su JSON. Las etapas del embudo del panel (Propuesto, Hipótesis de valor, POC, En desarrollo, En uso) y sus salidas (No aprobado, Descartado, Desenganchado) corresponden a las fases 0–7 de SEVEN-G, y el tiempo en cada etapa sale de las fechas de los eventos del registro: nunca se estima. Los umbrales de los indicadores, las etapas y los límites de días se configuran en config_panel.json.

Lo que T01 no registra queda «sin dato» y nunca se convierte en cero. La fase, el estado, la intensidad, las esferas y la ambición de SEVEN-G viajan en cada caso (bloque seveng).

Compañía, personas y proveedores son ficticios; cualquier parecido con una organización o persona real es casual. Los HTML generados nunca se editan a mano: se regeneran con el conector.

Cómo se usa: el panel se regenera solo, sin Python

El panel lleva incrustado el conector en JavaScript (t01_a_panel.js, la misma correspondencia T01 → panel que el generador) y se regenera en el navegador. No hay que instalar ni ejecutar nada:

  1. Con el registro de este navegador. Trabaje en el registro T01 y pulse «Panel del consejo (con este registro)»: el panel lee el registro guardado en este navegador (mismo sitio) y lo muestra. Mientras el registro sea el de ejemplo, se ve el panel de ejemplo.
  2. En la copia del sitio de la compañía (documento 03 §2.1): deje el JSON exportado por T01 en SEVEN-G/herramientas/datos/T01_registro.json; servido por http, el panel lo lee y lo muestra a toda la compañía. La ruta se configura en config_panel.json (navegacion.datos_t01).
  3. Con un fichero. «Cargar JSON» en el panel admite tanto un dashboard_data.json como el JSON completo de T01, que convierte al vuelo. En T01, «Descargar el JSON del panel» produce el dashboard_data.json con la misma correspondencia.
  4. Ajuste config_panel.json (umbrales, etapas y límites de días); la copia de la compañía debe regenerar los paneles de ejemplo (paso opcional siguiente) para que lleven su configuración incrustada.

Opcional, con Python 3.11 y uv: el generador t01_a_panel.py escribe los paneles como ficheros estáticos (para enviarlos por correo o mensajería, con la vista sin JavaScript y el registro de recomendaciones): 

uv run python t01_a_panel.py --t01 export_t01.json --salida carpeta
Sin argumentos genera este ejemplo en ejemplo/salida/. Sin Python, pwsh -File conector_js.ps1 -T01 registro.json -Salida dashboard_data.json produce el JSON del panel con Edge. Al cierre de cada sesión del consejo, motor/snapshot.py guarda una foto para ver la tendencia.

T17 · Board dashboard generatorTurns the T01 initiative register into the AI dashboard for the board and the recommendations log (T18)

What T17 is, in one sentence: it is a generator, not an application where data is entered. Initiatives are kept in the T01 register; T17 reads that register and generates —or regenerates, every time the register changes— the full board dashboard, its mobile version and the recommendations log. If you only want to see the result, open the example dashboard (in Spanish): full dashboard · mobile dashboard. The rest of this page explains how to generate it with your own data.

This connector takes the full JSON exported by the SEVEN-G T01 initiative register and converts it, without re-entering any data, into the AI dashboard for the board (full and mobile, in sync) and, if the register contains recommendations, into the recommendations log. The dashboards are generated by the engine included in the motor/ folder (version 8, with funnel and lifecycle; origin: AI en el Consejo, MIT, same author): no other repository is needed.

The register is the single data entry point: each initiative is entered in T01 like an opportunity in a CRM and the dashboard is rebuilt from its JSON. The dashboard funnel stages (Propuesto, Hipótesis de valor, POC, En desarrollo, En uso) and its exits (No aprobado, Descartado, Desenganchado) map to SEVEN-G phases 0–7, and the time in each stage comes from the dates of the register events: it is never estimated. Indicator thresholds, stages and day limits are configured in config_panel.json.

Anything T01 does not record is left as "no data" and is never turned into zero. SEVEN-G phase, status, intensity, spheres and ambition travel with each case (block seveng). Field names and on-screen texts are in Spanish, as in the engine.

How to use it: the dashboard regenerates itself, without Python

The dashboard embeds the connector in JavaScript (t01_a_panel.js, the same T01 → dashboard mapping as the generator) and regenerates itself in the browser. Nothing to install or run:

  1. With the register in this browser. Work in the T01 register and click "Board dashboard (with this register)": the dashboard reads the register saved in this browser (same site) and shows it. While the register is the sample one, the sample dashboard is shown.
  2. In the company's copy of the site (document 03 §2.1): leave the JSON exported by T01 in SEVEN-G/herramientas/datos/T01_registro.json; served over http, the dashboard reads it and shows it to the whole company. The path is configured in config_panel.json (navegacion.datos_t01).
  3. With a file. "Cargar JSON" in the dashboard accepts either a dashboard_data.json or the full T01 JSON, which it converts on the fly. In T01, "Download the dashboard JSON" produces the dashboard_data.json with the same mapping.
  4. Adjust config_panel.json (thresholds, stages and day limits); the company copy should regenerate the example dashboards (optional step below) so that they embed its configuration.

Optional, with Python 3.11 and uv: the t01_a_panel.py generator writes the dashboards as static files (to send them by e-mail or messaging, with the no-JavaScript view and the recommendations log): 

uv run python t01_a_panel.py --t01 export_t01.json --salida folder
With no arguments it builds this example in ejemplo/salida/. Without Python, pwsh -File conector_js.ps1 -T01 register.json -Salida dashboard_data.json produces the dashboard JSON with Edge. At the end of each board session, motor/snapshot.py saves a snapshot to see the trend.
