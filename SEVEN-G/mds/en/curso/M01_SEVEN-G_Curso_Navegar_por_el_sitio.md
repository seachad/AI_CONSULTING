## 1. Objective

By the end you will be able to find any document, template or tool, search for a term, download a PDF or a template in Word, change language and recognise the framework's codes.

---

## 2. Key ideas

1. **The site is a library, not a book.** Nobody reads it from start to finish: you enter through document 00, through the index or through this course, and move from link to link.
2. **Everything is linked.** When a text cites a document, a template (P) or a tool (T), the citation is a link.
3. **Every page has the same aids**: toolbar at the top, downloads area under the cover and "The essentials" box after the legal notice.
4. **Spanish and English are equivalent**: same content, same structure, same file name.

## 4. The codes

| Code | What it is | Where it is defined |
|---|---|---|
| **00 to 94** | Documents. The first digit indicates the block. | Index |
| **P01–P71** | Templates. P01–P31 are the evidence for each phase; P32–P71, those for the company, board, compliance, third parties, audit and implementation. | Block H |
| **T01–T22** | Tools. Those without their own application link to the procedure with which they are applied. | document 03 |
| **C1–C5** | Stages of the corporate cycle: diagnosis, direction, portfolio, oversight and review. | document 01 |
| **Phases 0–7 · G0–G5, R6, G7** | Phases of an initiative and their decision gates. | document 01 |
| **G3.05, LV-G3** | A gate criterion and the checklist for that gate. | document 21 · document 22 |
| **IA-AAAA-NNN** | Identifier of an initiative. | document 03 |
| **A0–A3 · S1–S4 · N1–N3 · D1–D7** | Agent autonomy · incident severity · supplier requirement level · maturity dimensions. | document 02 |

If in doubt, the glossary (document 02) rules.
