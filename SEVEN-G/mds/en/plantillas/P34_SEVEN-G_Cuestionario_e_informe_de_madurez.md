> **Why it matters.** The maturity assessment is a mandatory output of C1 and is repeated in C5 to check progress: with it, the board sets the thesis, the ambition and the risk appetite on a verified basis rather than on impressions. Without an answer sheet with evidence and verification, the level becomes a statement, the assessments of two years are not comparable and the company cannot substantiate the ten questions that support the SEVEN-G declaration of application (01 §14).

## 1. Instructions for use

| Aspect | Guidance |
|---|---|
| **When it is used** | In **C1 · Diagnosis** (baseline) and in **C5 · Review** (comparison), as a verified assessment. Between cycles, the AI Office may update it as a self-assessment, with no level value (11 §7.1). Also before an independent assessment or before publicly declaring that SEVEN-G is applied. |
| **Who completes it** | The lead assessor (head of the AI Office or external assessor) with the assessment team of at least two people. Nobody assesses a dimension whose practices they lead; if the AI Office leads D1, D2 or D7 practices, those dimensions are assessed by another member of the team or by a third party (11 §4.2). |
| **Who verifies it** | The independent verifier (internal audit, AI Auditor or third party), with the scope in 11 §4.6. The verifier may modify answers and records the change. |
| **Who decides or approves** | The promoter (chair of the AI Committee) approves the scope, cut-off date and team. The AI Committee approves the report and presents it to the board or its board committee; it does not modify answers and may only request a new verification. |
| **Stage of the corporate cycle** | C1 and C5. The result is published in the board dashboard (T17) and the actions that the board asks to be tracked are added to the register of recommendations (T18). |
| **Tool** | T15 · Maturity assessment: questionnaire of 84 questions with evidence and verification, calculation in 11 §5 with the D1 and D6 cap, comparison between assessments, interview guide, printable report with the seven sections in 11 §6 and JSON and CSV export of the answers. This template is its paper or spreadsheet equivalent. |
| **Reference document** | Document 11 (maturity model): dimensions and levels (§2), text of each question and required evidence (§3), method (§4), calculation (§5), report (§6), links (§7) and targets by ambition (§8). |
| **Lite versus Enterprise** | The questionnaire and the calculation are the same. Indicative duration: three to four weeks for a Lite scope and six to eight for Enterprise (11 §4.3). With an Enterprise scope, an independent assessment should also be carried out at least every two years (11 §4.1). |

Completion rules:

- The text of each question and the required evidence are in document 11 §3; this sheet records the code, the level and the markers. Questions are not reworded: the questionnaire version is recorded in section 2 and only assessments with the same version are compared.
- Possible answers (11 §4.5): **Yes**, **Partial**, **No, no evidence**, **No, contrary evidence** and **Not applicable** (only for questions marked *if applicable*, with verified justification). **Partial counts as not met.**
- An **unanswered question is left blank and counts as "no data"**: it is never treated as met or replaced by an estimate. If the only thing preventing a higher level is blank questions, the level of the dimension is "no data" and the minimum level reached is reported.
- Only evidence that exists and is applied on the **cut-off date** counts. An interview is an indication, not evidence: a "Yes" requires triangulation (11 §4.4).
- Questions marked **§14** substantiate the declaration of application; all of them are at level 3.

## 5. Calculation

### 5.1 Level by dimension

**Level = N**, the highest level for which all questions at levels 1 to N are "Yes" or "Not applicable" (11 §5.1). **Progress** to the next level = (Yes + 0.5 × Partial) ÷ applicable questions at level N + 1, as a percentage (11 §5.2). **Blocking criteria**: questions at levels 1 to N + 1 that are neither "Yes" nor "Not applicable". **Criteria met in advance**: questions at levels above N that are "Yes"; they do not raise the level.

| Dimension | Pending L1 | L2 | L3 | L4 | L5 | No data | Level | Progress | Blocking criteria | Criteria met in advance |
|---|---|---|---|---|---|---|---|---|---|---|
| D1 | | | | | | | | | | |
| D2 | | | | | | | | | | |
| D3 | | | | | | | | | | |
| D4 | | | | | | | | | | |
| D5 | | | | | | | | | | |
| D6 | | | | | | | | | | |
| D7 | | | | | | | | | | |

"Pending Ln" is the number of questions at level n that are neither "Yes" nor "Not applicable".

### 5.2 Spreadsheet formulas

With the answer sheet in columns (B = level, D = answer) and a named range per dimension (for example, `lev_D1` and `ans_D1`):

- Pending at level n: `=COUNTIFS(lev_D1,n)-COUNTIFS(lev_D1,n,ans_D1,"Yes")-COUNTIFS(lev_D1,n,ans_D1,"Not applicable")`.
- Dimension level, with the pending counts in P1 to P5: `=IF(P1>0,0,IF(P2>0,1,IF(P3>0,2,IF(P4>0,3,IF(P5>0,4,5)))))`. If all the pending questions at the next level are blank, record "no data" and the level obtained as the minimum.
- Progress, with the level in N: `=(COUNTIFS(lev_D1,N+1,ans_D1,"Yes")+0.5*COUNTIFS(lev_D1,N+1,ans_D1,"Partial"))/(COUNTIF(lev_D1,N+1)-COUNTIFS(lev_D1,N+1,ans_D1,"Not applicable"))`.
- Overall level, with the levels in `levels`, the weights in `weights` and the D1 and D6 levels in `lD1` and `lD6`: `=MIN(ROUNDDOWN(ROUND(SUMPRODUCT(weights,levels)/SUM(weights),2),0),MIN(lD1,lD6)+1)`.

## 7. Quality criteria

| # | Check | Status |
|---|---|---|
| 1 | Each "Yes" has valid evidence: it exists, is traceable, approved and current, shows application and predates the cut-off date (11 §4.5). | Met · Not met · Not applicable · Pending |
| 2 | No blank question has been counted as met or estimated: it is shown as no data. | |
| 3 | "Not applicable" only for questions marked *if applicable* and with verified justification. | |
| 4 | Each dimension has at least two interviews from different functions and nobody has assessed a dimension whose practices they lead. | |
| 5 | The samples have the minimum size, are stratified and were selected by the assessment team. | |
| 6 | The verifier reviewed all "Yes" answers in D1 and D6, all §14 questions and at least 25 % of the other "Yes" answers. | |
| 7 | Level by dimension and overall level calculated with the rule in 11 §5; the report states whether the D1 or D6 cap was applied. | |
| 8 | The weights are declared, between 10 % and 25 %, and match those of the assessment used for comparison. | |
| 9 | The comparison only uses verified assessments with the same questionnaire version. | |
| 10 | Each improvement action has an owner, a deadline and a closure criterion; those requested by the board are in T18. | |
